# 全面 Code Review 设计

## 目标

对 utoland 项目进行全面 code review，涵盖架构重构、无用代码清理、代码质量优化。

## 范围

- 58 个 GDScript 文件（跳过 placement 相关）
- 22 个场景文件
- 测试文件不在修改范围内（但重构后需确保 195 个测试全部通过）

## 决策

- 塔防布置系统（placement）保留不动
- `scenes/backup/` 废弃场景直接删除
- 在 `feature/code-review` 分支上工作

## 三轮执行计划

### 第一轮：架构重构

#### 1.1 拆分 shop_manager.gd（350行 → 3个文件）

当前混合 5 个职责：稀有度权重、价格计算、物品生成、效果应用、UI 渲染。

| 文件 | 职责 | 预估行数 |
|------|------|----------|
| `shop_manager.gd` | 商店流程控制（生成/购买/刷新），协调其他模块 | ~120 |
| `shop_item_generator.gd` | 稀有度权重、物品池筛选、价格计算、4槽生成 | ~100 |
| `shop_effect_applier.gd` | 14种效果的 match 分发 + 效果应用逻辑 | ~130 |

shop_manager.gd 持有另外两个模块的引用，对外接口不变。

#### 1.2 消除 game_data.gd 初始化重复

reset() 方法 68 行与类级别字段默认值重复。方案：提取默认值为常量字典，reset() 和声明从同一数据源读取。

### 第二轮：清理删除

- 删除 `scenes/backup/` 目录（6个废弃场景）
- 扫描未被引用的死代码（函数、变量、信号）
- 清理无用的 preload/load 引用

### 第三轮：广度扫描

- 补充缺失的类型标注（函数参数、返回值）
- 提取魔法数字到常量或 Resource
- 修正脚本内成员顺序（信号→常量→@export→@onready→变量→生命周期→公共→私有）
- 查漏代码风格一致性
