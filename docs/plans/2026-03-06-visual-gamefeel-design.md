# 视觉与打击感优化设计

## 目标

将游戏的视觉表现和打击感提升到土豆兄弟（Brotato）的水平。本轮专注视觉+打击感，不含音效和 UI 动效。

## 方案

采用"先系统后美术"策略：先搭建通用的游戏手感系统，再替换像素风美术资源。

## 实施阶段

### 阶段一：游戏手感基础系统

#### 1.1 屏幕震动 (CameraShake)

在玩家 Camera2D 上通过 offset 偏移实现震动：

| 触发场景 | 强度 | 持续时间 |
|----------|------|----------|
| 玩家受击 | 3px | 0.1s |
| 敌人击杀 | 2px | 0.08s |
| 波次开始 | 5px | 0.2s |

实现：Tween 驱动 camera.offset，多次叠加取最大值。

#### 1.2 击退系统 (Knockback)

敌人受伤时产生击退：
- 方向：弹道方向（子弹）/ 玩家→敌人方向（回旋镖/激光）
- 距离：15px，持续 0.1s，Tween 缓动
- 击退期间敌人仍可被攻击

#### 1.3 受击闪白 (Hit Flash)

敌人/玩家受击时 modulate 闪白 0.05s，后续换精灵图后改用 shader。

#### 1.4 无敌帧闪烁

玩家受击后 0.5s 无敌期间 modulate.a 交替 0.3/1.0（间隔 0.08s），结束恢复 1.0。

### 阶段二：视觉反馈层

#### 2.1 伤害数字

敌人受击时弹出伤害数字：
- 上浮 30px + 左右随机 ±10px，持续 0.6s，后半段淡出
- 大伤害（≥30）放大 1.3x + 黄色
- Label + Tween，播完 queue_free()

#### 2.2 敌人死亡特效

GPUParticles2D 爆炸粒子，8-12 个小方块碎片四散，颜色与敌人一致，持续 0.3s，带重力。通过 SceneFactory 创建。

#### 2.3 金币拾取特效

拾取时金币缩小 + 淡出（0.15s），可选金色小粒子上冒。

#### 2.4 击中特效 (Hit Sparks)

子弹击中敌人时 4-6 个白色/黄色粒子从击中点外扩，持续 0.15s。

### 阶段三：武器视觉增强

#### 3.1 步枪

- 枪口闪光：射击时发射点白色闪光 1 帧
- 子弹拖尾：Line2D 2-3 点，黄色→透明，长度 15px
- 击中触发通用 hit sparks

#### 3.2 回旋镖

- 旋转：每秒 720° 持续旋转
- 拖尾：Line2D 青色→透明，5-6 点
- 返回阶段拖尾变亮 + 加速旋转

#### 3.3 激光

- 加粗：Line2D 宽度 2px→4px，中心白→边缘红渐变
- 击中闪光：末端小型闪光圆圈
- 频闪：发射时全屏红色 flash（alpha 0.03，0.05s）

### 阶段四：像素风精灵图替换

#### 资源规格

- 标准实体：16×16 像素（缩放到 30×30）
- 大型实体（Tank）：24×24 像素（缩放到 45×45）
- 小型实体（子弹/金币）：8×8 像素
- 调色板：统一有限调色板

#### 替换清单

| 实体 | 当前 | 目标 |
|------|------|------|
| 玩家 | 绿色 ColorRect | 像素角色（3 角色不同造型） |
| 普通敌人 | 红色 ColorRect | 像素怪物 |
| 快速敌人 | 红色 ColorRect | 不同造型敌人 |
| 坦克敌人 | 红色 ColorRect | 大型像素怪物 |
| 射手塔 | 绿色 ColorRect | 像素炮台 |
| 墙壁塔 | 绿色 ColorRect | 像素路障 |
| 减速塔 | 绿色 ColorRect | 像素水晶/法阵 |
| 子弹 | 黄色 ColorRect | 像素子弹 |
| 回旋镖 | 青色圆形 | 像素回旋镖 |
| 金币 | 金色圆形 | 像素金币（旋转动画） |

#### 动画帧

- 玩家：idle 2帧、walk 4帧、被击 1帧
- 敌人：idle/walk 2-4帧
- 金币：旋转 4帧循环
- 塔：idle 1-2帧呼吸光效

#### 素材来源

itch.io 像素素材包，关键词：pixel art roguelike / top-down enemies / tower defense。具体素材由用户挑选，代码框架先搭好。

## 不在本轮范围

- 音效和背景音乐
- UI 交互动效和场景切换过渡
- 塔防玩法优化
- 游戏平衡性调整
