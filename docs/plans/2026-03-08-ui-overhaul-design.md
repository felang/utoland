# UI 全面重做设计

日期：2026-03-08

## 目标

系统性重做全部游戏 UI，解决以下核心问题：
- 无主题系统，样式散落各处
- 硬编码定位，不适配分辨率
- HUD 不可读，无背景/颜色编码
- 商店节点命名混乱，无物品描述
- 角色选择全靠代码生成
- 结算屏过于简陋
- 无悬停/聚焦反馈

## 设计风格

**扁平简约 + 少量科幻点缀**（类似 Brotato / Halls of Torment）：
- 半透明深色面板，不遮挡战斗
- 高对比度文字和图标
- 关键数值颜色编码
- 稀有度边框发光

目标平台：键鼠优先，后续可能适配手柄。

|------|------|
| `resources/ui/game_theme.theme` | Godot Theme 资源，定义所有控件默认样式 |

### 配色方案
| 用途 | 色值 |
|------|------|
| 主背景 | `#1a1a2e` |
| 面板背景 | `#16213e` |
| 强调色/危险 | `#e94560` |
| 金币 | `#ffd700` |

### 字号层级

- 正文：18px

- **按钮**：圆角 8px，悬停高亮，点击缩放动画，禁用态灰色
- **面板**：圆角 12px，半透明深色背景 `#16213e` + alpha，1px 亮边

## 第二部分：HUD 重做

### 现状
两行纯文本（`HP: X | Coins: Y` / `Wave: X/10 | Time: X.X`），无背景，字体小。

### 新布局
```
顶部栏（半透明渐变条）
❤ ██████░░ 80/100    🪙 156    ⚔ Wave 3/10  ⏱ 25s    击杀: 42

                    （战斗区域）

底部 Buff 栏
[穿甲x2] [暴击10%] [吸血5%] [护盾x1] [减速光环]
```

### 元素说明
| 元素 | 设计 |
|------|------|
| HP 条 | ProgressBar 自定义样式，绿→黄→红渐变（按百分比），数字叠加 |
| 金币 | 金色图标 + 数字，获取时弹跳动画 |
| 波次 | `Wave X/10`，切换时闪烁提示 |
| 倒计时 | 整数秒，最后 5 秒变红闪烁 |
| Buff 栏 | 底部水平排列，图标 + 简短文字，从 GameData 读取激活状态 |
| 击杀计数 | 右上角显示本波击杀数 |

### 技术方案
- `MarginContainer` + `HBoxContainer` 锚定顶部/底部
- `ProgressBar` 自定义 StyleBox 做 HP 条
- Buff 栏动态生成：遍历 GameData 中 pierce_count/multishot_active/lifesteal_ratio 等字段

│  │ 投射物穿透+1个敌人   │  │ 10%概率双倍伤害     │   │
│  │ 🔒     💰 45 [购买] │  │ 🔒     💰 30 [购买] │   │
│  └────────────────────┘  └────────────────────┘   │
│  ┌─物品卡片3──────────┐  ┌─物品卡片4──────────┐   │
│  │ 磁铁               │  │ 自动冲刺            │   │
│  │ 金币拾取范围+50%    │  │ 每10秒自动冲刺      │   │
│  │ 🔒     💰 20 [购买] │  │ 🔒     💰 60 [购买] │   │

### 关键改动
| 元素 | 设计 |
|------|------|
| 布局 | 全屏覆盖，2x2 卡片网格 |
| 物品卡片 | 场景模板 `shop_item_card.tscn`，名称+描述+价格，稀有度整卡边框发光，亲和标签角标 |
| 已购标记 | 灰化 + "已拥有" 覆盖 |
| 角色属性面板 | 底部常驻，显示当前全部属性，买入后实时高亮变化值 |
| 锁定按钮 | 图标按钮替代 emoji |
| 刷新按钮 | 显示费用，余额不足禁用 |
| 悬停效果 | 卡片悬停放大 + 详细描述 |

### 技术方案
- 创建 `scenes/ui/shop_item_card.tscn` 场景模板
- shop_manager 通过实例化模板填充 4 个槽位，统一接口
- 属性面板从 GameData 读取，买入物品后 tween 高亮变化值

## 第五部分：开始菜单

### 现状
一个标题 + 一个按钮。

### 新设计
- 深色渐变背景
- 标题 + 副标题/版本号
- 按钮竖排居中：开始游戏 / 设置（占位） / 退出
- 按钮悬停缩放 + 高亮动画
- 右下角版本号

## 第六部分：地图选择

### 现状
硬编码两张卡片，无预览。

### 新设计
- **数据驱动**：从 `GameConfig.maps` 动态生成卡片
- 卡片用 `MapData.fallback_color` 作为预览色块背景
- 悬停放大 + 边框高亮
- 返回按钮可回到角色选择

---

## 第七部分：结算屏

### 现状
胜利/失败 + 存活波次 + 两个按钮。

### 新设计
- **波次进度条**：可视化展示走到了哪一波
- **战绩统计面板**：击杀总数、获取金币、购买物品数、受到伤害、最高连杀
- **已购物品展示**：本局获得的所有物品图标列表
- **按钮**：再来一局（直接进角色选择） / 主菜单

### 数据需求
GameData 新增统计字段：
- `total_kills: int`
- `total_coins_earned: int`
- `total_damage_taken: float`
- `max_kill_streak: int`
- `purchased_item_list: Array[String]`

在战斗中（enemy 死亡、player 受伤）和商店中（购买物品）累计。
