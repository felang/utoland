### 碰撞层设计
- Layer 1: 玩家
- Layer 2: 敌人
- Layer 3: 植物塔
- Layer 4: 玩家子弹

### 节点组系统
- "player": 玩家节点
- "enemies": 所有敌人
- "towers": 所有塔
- "wave_manager": 波次管理器

### 场景结构
```
main.tscn
├── Player (CharacterBody2D)
│   └── Camera2D
├── EnemySpawner (Node)
├── WaveManager (Node)
├── TowerWall × 3 (StaticBody2D)
└── HUD (CanvasLayer)
```
