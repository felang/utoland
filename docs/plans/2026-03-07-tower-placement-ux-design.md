# 塔布置交互优化设计

## 目标

优化布置阶段的交互体验，让玩家更直观地理解放置规则和塔的能力。

## 设计决策

### 1. 全地图网格线

- 布置场景中始终显示淡色网格线（30px 格子）
- 用 `_draw()` + `draw_line()` 在背景层绘制
- 颜色：半透明白/灰（如 `Color(1, 1, 1, 0.15)`）
- 覆盖整个地图区域（MAP_PIXEL_WIDTH x MAP_PIXEL_HEIGHT）

### 2. 攻击范围圈

- **预览时**：拖拽塔跟随鼠标时，显示该塔类型的 `attack_range` 为半透明圆圈
- **点击已有塔时**：点击场上已放置的塔，显示其攻击范围圈；点击空白处或开始拖新塔时隐藏
- 墙塔（`attack_range == 0`）不显示范围圈
- 圆圈样式：半透明填充 + 边框线（淡蓝色）

### 3. 放置合法性反馈

- 能放置时：预览塔 `modulate = Color(1, 1, 1, 0.5)`（现状）
- 不能放置时：预览塔 `modulate = Color(1, 0.3, 0.3, 0.5)`（半透明红色）
- 每帧鼠标移动时通过 `_can_place_at()` 实时更新颜色

### 4. 移除已放置的塔

- 非预览状态下，右键点击已放置的塔 → 移除该塔，全额退还金币
- 检测点击位置最近的塔（距离 < GRID_SIZE / 2）
- 移除后更新 UI 金币显示

## 不做的事

- 不改 UI 布局（按钮位置/样式保持现状）
- 不加拖拽移动已放置塔的功能
- 不加音效（后续单独做）

## 技术要点

- 网格绘制：新建 `GridOverlay`（Node2D）子节点，override `_draw()`
- 范围圈绘制：新建 `RangeIndicator`（Node2D）子节点，override `_draw()`，动态设置 radius
- 塔类型的 `attack_range` 从 `TowerData` Resource 读取
- 移除塔时需要从 towers 分组中查找最近的塔并退还 `SceneFactory.get_tower_cost(tower_type)` 金币
