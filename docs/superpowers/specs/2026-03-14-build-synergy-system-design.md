# 构筑协同系统设计

## 概述

为 utoland 设计角色+武器+植物塔的构筑协同系统，引入标签羁绊（主系统）和手工配对协同（副系统），让玩家在 15 波战斗中体验"探索→定型→成型"的构筑成长过程。

## 设计目标

1. 角色、武器、塔三者交织形成有深度的构筑体系
2. 玩家有清晰的构筑方向感，同时保留灵活性
3. 成长过程有云顶之弈式的"前期探索、中期定型"节奏
4. 少量手工配对协同作为高阶发现乐趣

## 一、标签羁绊系统

### 1.1 标签定义

5 个战术功能标签，按实际玩法定位划分：

| 标签 | 英文 ID | 核心幻想 |
|------|---------|----------|
| 猛攻 | assault | 高伤害快速清场 |
| 控制 | control | 减速/定身/击退，限制敌人行动 |
| 爆破 | blast | AOE 范围毁灭 |
| 坚守 | fortify | 耐久/减伤/回复 |
| 增益 | boost | 增强队友/经济加速 |

### 1.2 羁绊阶梯

三档触发：**2/3/5**

- **2 档**：容易触发，给玩家早期方向感（纯数值加成）
- **3 档**：中期定型标志，引入小机制（质变体验）
- **5 档**：all-in 终极回报，强力机制（占 8 人口的 62.5%，意味着放弃第二个 3 档羁绊）

核心抉择：**5 档 all-in** vs **3+3 双羁绊**（广度 vs 深度）

### 1.4 羁绊效果

#### 猛攻（Assault）

| 档位 | 效果 |
|------|------|
| 2 | 所有猛攻单位 +15% 伤害 |
| 3 | **狂热**：击杀敌人后 3 秒内攻速翻倍 |
| 5 | **溢杀**：击杀敌人时，溢出伤害的 30% 以爆炸形式伤害周围敌人 |

#### 控制（Control）

| 档位 | 效果 |
|------|------|
| 2 | 所有控制效果持续时间 +25% |
| 3 | **脆弱标记**：被控制的敌人受到全体伤害 +20% |
| 5 | **连锁控制**：控制效果到期时触发 1 秒冻结，冻结不可叠加 |

#### 爆破（Blast）

| 档位 | 效果 |
|------|------|
| 2 | AOE 范围 +20% |
| 3 | **殉爆**：AOE 伤害有 15% 几率触发二次爆炸（伤害 50%） |
| 5 | **战术轰炸**：每 15 秒对屏幕内随机 3 个敌人群落投下轰炸 |

#### 坚守（Fortify）

| 档位 | 效果 |
|------|------|

| 档位 | 效果 |
|------|------|

## 二、角色被动（重新设计）

角色被动和标签方向联动，但与羁绊效果互补而非重叠：

| 角色 | 标签 | 被动名称 | 效果 |
|------|------|----------|------|
| Kaze（风） | 猛攻 | **疾风连击** | 连续命中同一目标时，每次叠加 5% 伤害（最高 +30%，换目标重置） |
| Nemo（尼莫） | 控制 | **控场大师** | 自己施加的控制效果范围 +30% |
| Gorg（格格） | 爆破 | **血怒** | 每损失 10% 最大生命值，AOE 伤害 +5%（最高 +50%） |
| Dora（朵拉） | 坚守 | **坚壁回馈** | 每 5 秒回复 2% 最大生命值；坚守单位存活数量 ≥3 时回复翻倍 |
| Merlin（梅林） | 增益 | **增幅领域** | 增益类单位的效果范围 +40% |

**设计原则**：
- 每个被动强化角色在对应标签方向的独特能力
- 和羁绊效果互补而非叠加同一维度
- 不选对应角色也能玩该标签，只是少了这层加成

## 三、手工配对协同（6 对）

同时拥有指定的两个单位即可触发（任意等级）：

| # | 组合 | 名称 | 效果 | 类型 |
|---|------|------|------|------|
| 1 | 冰枪 + 藤蔓 | **极寒囚笼** | 被藤蔓定身的敌人如果同时处于冰枪减速状态，定身结束后进入 2 秒冻结（无法被攻击也无法移动） | 同标签深度（控制） |
| 2 | 火箭炮 + 爆竹竹 | **连环引爆** | 爆竹竹的蓄力爆炸会引爆范围内所有火箭炮的未爆弹头，造成额外 50% 伤害 | 同标签深度（爆破） |
| 3 | Gorg + 刀刃 | **嗜血狂战** | Gorg 装备刀刃时，击杀回复 5% 最大生命值 | 角色+武器专属 |
| 4 | Merlin + 薄荷 | **魔力共鸣** | 薄荷的增益效果不再衰减距离，全图生效 | 同标签深度（增益） |
| 5 | 闪电 + 冰花 | **超导风暴** | 被冰花减速的敌人受到闪电伤害时，连锁次数 +2 且不衰减 | 跨标签（爆破+控制） |
| 6 | Kaze + 加特林 | **弹幕时刻** | Kaze 装备加特林时，每 50 发子弹触发一次 0.5 秒的子弹时间（全屏敌人减速 80%，自己正常射击） | 角色+武器专属 |

**设计原则**：
- 3 对同标签内深度协同（#1 控制、#2 爆破、#4 增益）
- 2 对角色+武器专属组合（#3、#6），强化角色身份感
- 1 对跨标签隐藏协同（#5），奖励探索型玩家
- 每对效果都是机制性的，不只是数值

## 四、成长节奏（15 波）

### 4.1 阶段划分

| 阶段 | 波次 | 人口 | 构筑目标 |
|------|------|------|----------|
| **开荒期** | 1-3 波 | 2-3 | 买低费单位站住脚，触发首个 2 档羁绊 |
| **探索期** | 4-7 波 | 3-5 | 试不同标签，决定主方向。1 个 3 档或 2 个 2 档 |
| **定型期** | 8-11 波 | 5-7 | 主羁绊 3 档锁定，凑副羁绊。核心追 Lv2 |
| **成型期** | 12-15 波 | 7-8 | 冲 5 档或 3+3。核心追 Lv3。配对协同上线 |

### 4.2 成长感节点

| 节点 | 玩家感受 |
|------|----------|
| 首次触发 2 档羁绊 | "有方向了" |
| 升到 3 档 | "构筑成型了"（质变机制上线） |
| 三合一出 Lv2 | "核心单位变强了" |
| 发现配对协同 | "这两个一起用这么强？" |
| 冲到 5 档 | "all-in 值了！"（终极回报） |
| 三合一出 Lv3 | "毕业了" |

### 4.3 典型成型构筑示例

#### 例一：猛攻 5 all-in（Kaze）

> Kaze（猛攻）+ 步枪Lv2 + 加特林Lv3 + 霰弹枪 + 仙人掌Lv2 + 玫瑰 + 冰花 + 冰枪
> - 猛攻 5 档：溢杀爆炸
> - 控制 2 档：控制时间 +25%
> - 配对协同：Kaze + 加特林 = 弹幕时刻
> - 被动：疾风连击叠加集火伤害

#### 例二：控制 3 + 坚守 3 双羁绊（Nemo）

> Nemo（控制）+ 冰枪Lv2 + 刀刃 + 冰花 + 藤蔓Lv2 + 蒲公英 + 树桩Lv2 + 橡树
> - 控制 3 档：脆弱标记
> - 坚守 3 档：应急护盾
> - 配对协同：冰枪 + 藤蔓 = 极寒囚笼
> - 被动：控场大师扩大控制范围

#### 例三：增益 3 + 爆破 3 混合（Merlin）

> Merlin（增益）+ 激光Lv2 + 火箭炮 + 薄荷Lv3 + 向日葵 + 荆棘 + 蘑菇 + 爆竹竹
> - 增益 3 档：自增益（薄荷自己也获得加成）
> - 爆破 3 档：殉爆
> - 配对协同：Merlin + 薄荷 = 魔力共鸣（全图增益）
> - 被动：增幅领域扩大增益范围

## 五、与现有系统的关系

### 5.1 需要修改的现有系统

- **CharacterData**：新增 `tag: StringName` 字段，删除旧被动字段，新增新被动相关字段
- **WeaponData / TowerData**：新增 `tag: StringName` 字段
- **GameData**：新增羁绊计算逻辑、配对协同检测
- **角色被动系统**：重写 5 个被动的实现
- **波次配置**：从 8 波扩展到 15 波

### 5.2 新增系统

- **SynergyManager**：羁绊计算与效果管理（计算当前标签计数、触发/移除羁绊效果）
- **PairSynergyManager**：配对协同检测与效果管理
- **羁绊 UI**：在 HUD 或商店界面显示当前激活的羁绊状态

### 5.3 不变的系统

- 三合一合成机制（不影响羁绊计数）
- 商店刷新/购买/卖出流程
- 人口等级系统（1-7 级，2-8 人口）
- SceneFactory 工厂模式
- Hitbox/Hurtbox 伤害体系
