# 角色系统实施总结

**实施日期**: 2026-03-04
**版本**: v0.4.0

## 实施内容

### 1. 角色配置（game_config.gd）
- 添加 CHARACTERS 配置字典
- 定义三个角色：warrior（战士）、ranger（游侠）、tank（坦克）
- 每个角色包含 8 个属性字段：
  - `max_hp`: 最大生命值
  - `speed`: 移动速度
  - `damage_mult`: 伤害倍率
  - `attack_speed_mult`: 攻击速度倍率
  - `hp_regen`: 生命回复速度
  - `name`: 角色显示名称
  - `description`: 角色描述
  - `color`: 角色主题颜色

### 2. GameData 支持（game_data.gd）
- 添加 `current_character: String` 变量存储当前选择的角色
- 实现 `init_character(character_id: String)` 方法初始化角色属性
- 修改 `reset()` 方法，在重置时初始化角色到 player_stats
- 添加 `hp_mult: float` 倍率字段支持商店生命值升级

### 3. 玩家集成（player.gd）
- 从 GameData 读取角色属性而非硬编码
- 应用所有倍率系统：
  - 最大生命值 = 角色基础值 × hp_mult
  - 移动速度 = 角色基础值 × speed_mult
  - 伤害 = 角色基础值 × damage_mult
  - 攻击速度 = 角色基础值 × attack_speed_mult
- 实现生命回复机制：
  - 基础回复 = 角色 hp_regen
  - 商店回复 = GameData.player_stats.hp_regen
  - 总回复 = 基础回复 + 商店回复

### 4. 角色选择界面（character_selection.tscn/gd）
- 创建 UI 场景，包含三个角色按钮
- 每个按钮显示角色名称和描述
- 实现角色选择逻辑：
  - 点击按钮调用 `_on_character_selected(character_id: String)`
  - 更新 `GameData.current_character`
  - 切换到塔布置场景

### 5. 场景流程调整
- 修改场景切换流程：
  - 开始菜单 → 角色选择 → 塔布置 → 主游戏
- 更新 `start_menu.gd`：
  - 开始游戏按钮切换到角色选择场景
  - 添加类型注解和错误处理

### 6. 商店系统调整（shop_manager.gd）
- 生命值升级改为倍率系统：
  - 不再直接增加 max_hp
  - 改为增加 hp_mult（+0.2 每次升级）
- 生命回复升级正确叠加：
  - 角色基础 hp_regen 保持不变
  - 商店升级增加 player_stats.hp_regen
  - player.gd 中两者相加

## 技术细节

### 配置驱动架构
所有角色数值集中在 `GameConfig.CHARACTERS` 管理，遵循项目的配置驱动原则。禁止硬编码，确保数值易于调整和平衡。

### 倍率系统
采用倍率系统而非固定值增加，确保升级效果与角色基础属性成比例：
- 角色提供基础属性
- 商店升级提供倍率加成
- 最终属性 = 基础属性 × 倍率

这种设计使得不同角色的升级效果保持平衡。

### 状态管理
使用 GameData 单例管理角色状态，确保跨场景数据持久化：
- `current_character` 存储选择的角色 ID
- `init_character()` 在角色选择后初始化属性
- `reset()` 在游戏重置时重新初始化角色

### 类型安全
所有新增代码遵循类型注解规范：
- 变量声明包含类型
- 函数参数和返回值包含类型
- 提高代码可读性和错误检测
