# Utoland

一个结合塔防和生存射击元素的 2D 游戏，使用 Godot 4.6 开发。

## 项目简介

**Utoland** 是一款融合了塔防策略和动作射击的游戏。玩家需要在波次间布置防御塔，并在战斗中使用武器击败敌人，通过商店系统强化角色和防御，最终挑战 10 波敌人攻势。

**当前版本**: MVP v0.3.1
**最后更新**: 2026-03-04

## 核心玩法

1. **武器选择** - 选择初始武器（步枪/霰弹枪/狙击枪）
2. **塔布置** - 使用金币在网格地图上布置防御塔
3. **战斗** - WASD 移动，自动瞄准射击，击败敌人
4. **商店** - 波次间购买属性升级、新塔、医疗包
5. **循环** - 重复布置→战斗→商店，直到通关或失败

## 技术栈

- **游戏引擎**: Godot 4.6
- **编程语言**: GDScript
- **物理引擎**: Jolt Physics
- **渲染方式**: GL Compatibility
- **分辨率**: 1920x1080 (全屏)

## 快速开始

### 运行游戏

1. 使用 Godot 4.6 打开项目目录
2. 主场景：`scenes/ui/start_menu.tscn`
3. 按 `F5` 运行游戏

### 调整游戏数值

所有游戏数值集中在 `game_config.gd` 中管理：

```gdscript
# 修改武器伤害
const WEAPONS = {
    "rifle": {
        "damage": 10.0,  # 修改这里
        ...
    }
}
```

详见 [配置系统文档](CONFIGURATION.md)

## 核心特性

### 已实现功能

- ✅ 三种武器系统（步枪/霰弹枪/狙击枪）
- ✅ 三种防御塔（射手塔/墙塔/减速塔）

- ✅ 10 波递进难度系统
