# Utoland

一个基于 Godot 4.6 的 2D 塔防+生存射击游戏。

## 项目概述

Utoland 是一个结合了塔防和生存射击元素的游戏。玩家需要在战斗前布置防御塔，然后在战斗中控制角色击败敌人波次。

## 技术栈

- **引擎**: Godot 4.6
- **语言**: GDScript
- **物理引擎**: Jolt Physics
- **渲染方法**: GL Compatibility

## 核心特性

### 配置驱动架构

所有游戏数值集中在 `game_config.gd` 中管理，包括：
- 角色属性
- 防御塔配置
- 敌人配置
- 波次配置
- 商店价格和升级倍率

### 角色系统

游戏支持三个可选角色，每个角色有不同的属性：

#### 角色列表

- **战士**：高生命值（150 HP），低速度（180），高伤害倍率（1.2x）
- **游侠**：低生命值（80 HP），高速度（250），高攻速倍率（1.1x）
- **坦克**：超高生命值（200 HP），极低速度（150），带生命回复（1.0/秒）

#### 角色选择

在开始游戏后，玩家可以在角色选择界面选择角色。角色属性会影响：
- 最大生命值
- 移动速度
- 伤害倍率
- 攻击速度倍率
- 生命回复速度

#### 商店升级

商店升级使用倍率系统，与角色基础属性叠加：
- 生命值升级：+20% 倍率（叠加）
- 伤害升级：+10% 倍率
- 攻击速度升级：+10% 倍率
- 移动速度升级：+10% 倍率

### 防御塔系统

玩家可以在战斗前布置防御塔：
- **基础塔**：平衡的攻击和射程
- **狙击塔**：高伤害，低攻速
- **机枪塔**：低伤害，高攻速

### 波次系统

敌人分波次出现，每波难度递增：
- 敌人数量增加
- 敌人生命值提升
- 敌人速度加快

### 商店系统

战斗间隙可以使用金币购买升级：
- 角色属性升级（生命、伤害、攻速、移动速度）
- 防御塔购买

## 游戏流程

1. **开始菜单** - 选择开始游戏或退出
2. **角色选择** - 选择战士、游侠或坦克
3. **塔布置** - 在地图上放置防御塔
4. **战斗** - 控制角色击败敌人波次
5. **商店** - 使用金币购买升级
6. **重复** - 继续下一波次

## 开发工具

### GDAI MCP 插件

项目集成了 GDAI MCP 插件，支持 AI 辅助开发：
- 自动化场景创建
- 节点操作
- 脚本调试
- 项目信息查询

### 开发规范

项目遵循严格的开发规范：
- **配置驱动**：禁止硬编码，所有数值从 GameConfig 读取
- **状态管理**：使用 GameData 单例管理跨场景状态
- **类型注解**：所有变量和函数必须有类型注解
- **属性识别**：使用属性而非节点名称识别对象

详见 `.claude/rules/` 目录。
